# Пульс — лендинг

Рекламная страница для скачивания приложения «Пульс» (RuStore, Google Play).

## Запуск локально

Откройте `index.html` в браузере или запустите простой сервер:

```powershell
cd C:\Users\Дарья\pulse-landing
python -m http.server 8080
```

Затем откройте: http://localhost:8080

## Скриншоты

Положите в папку `assets/`:

- `screen-home.png` — главный экран
- `screen-operation.png` — детали операции

## Настройка

- **Ссылки на магазины:** в `index.html` замените `#` у кнопок RuStore и Play Market на реальные URL.
